# ThriftX 👕♻️

### Redefining Sustainable Fashion Through Technology

ThriftX is a modern thrift-fashion platform built to make sustainable shopping more accessible, affordable, and stylish for the next generation. The platform combines clean UI/UX, scalable web technologies, and an innovative digital marketplace experience to promote circular fashion and conscious consumerism.

---

## 🚀 About The Project

Fast fashion has created massive environmental and economic challenges. ThriftX was built with the vision of transforming the way people discover and shop for fashion by encouraging the reuse and circulation of pre-loved clothing in a modern and engaging way.

The platform focuses on:

* Sustainable fashion accessibility
* Affordable style discovery
* User-centric digital experience
* Scalable marketplace architecture
* Modern web development practices

---

* 🛍️ Interactive thrift-fashion marketplace

## 🧠 Problem Statement

Millions of fashion products go to waste every year due to overconsumption and lack of accessible resale ecosystems. Traditional thrift shopping often lacks:

* Convenience
* Digital accessibility
* Personalized discovery
* Modern user experience

ThriftX aims to bridge this gap by building a digital-first thrift ecosystem that feels as seamless and attractive as modern e-commerce platforms.

## ⚙️ Installation & Setup

### Clone the repository

```bash
git clone https://github.com/bpsd07/thriftxBPSD.git
```

### Navigate to project folder

```bash
cd thriftxBPSD
```

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm start
```
